# Security Policy

## Supported Versions

| Version | Supported |
|---------|-----------|
| Latest release | Yes |
| Older releases | No — update to the latest release |

## Reporting a Vulnerability

**Do NOT open a public issue for security vulnerabilities.**

To report a vulnerability:

1. Join the [Discord server](https://discord.gg/denat8G6ze)
2. Send a direct message to a maintainer describing the issue

We aim to acknowledge reports promptly and will credit reporters in
release notes unless they prefer otherwise.
