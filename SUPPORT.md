# Support

## Getting help

| Channel | Best for |
|---------|----------|
| [GitHub Issues](../../issues) | Bugs, feature requests, tracked work |
| [Discord](https://discord.gg/denat8G6ze) | Quick questions, community help, discussion |

## Before you file

1. Update to the [latest release](../../releases/latest) — your issue
   may already be fixed
2. Search [existing issues](../../issues) to avoid duplicates

## What to include in a bug report

- App version and GPU (DX12 Ultimate features are required)
- Windows build number
- Which visualization mode was active
- Whether the issue is visual, audio (no capture/stuttering), or a crash
- The log file from `%LOCALAPPDATA%\RTXAudioVisualizer\logs\` if the app
  produced one
